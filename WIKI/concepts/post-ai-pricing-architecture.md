# Post-AI Pricing Architecture — Value-Capture Hybrid Model

> Framework for pricing an AI-native infrastructure firm. Shifts billing from inputs (hours/headcount) to infrastructure + outputs (capacity, compute, business metrics). Source: Google AI (Gemini) analysis prompted by Jay — `Google AI Pricing Model v0.1.md` in the vault root.

## The Core Shift

Traditional consulting bills hours and headcount. Post-AI infrastructure bills software capacity, compute, and verifiable business outcomes. The pricing architecture is a **four-layer hybrid**:

### Layer 1: Implementation Fee (Cost-Recovery Setup)
- **Structure:** Fixed, low-margin setup & deployment fee (~$15K–$25K flat)
- **Covers:** Data pipeline cleaning, core OS deployment, engineering sprint costs
- **Purpose:** Replaces the traditional $100K+ discovery/PowerPoint phase with automated ingestion

### Layer 2: Core Infrastructure Subscription (SaaS Component)
- **Structure:** Tiered monthly subscription by operational data volume or active autonomous agents
- **Pricing:** $2,500–$5,000/month
- **Covers:** Continuous model fine-tuning, software updates, data sovereignty security, API hosting

### Layer 3: Computation & Capacity Metric (Usage Component)
- **Structure:** Usage-based — per 1,000 executed workflows or processed data clusters
- **Purpose:** Align cost with business activity (10K invoices in Q4 = more; slow Q1 = less)
- **Critical:** Token/compute volume must be accounted for so Exo doesn't lose money on adverse pricing

### Layer 4: Value-Share Tracker (Performance Lever)
- **Structure:** Percentage of verifiable cost reduction or revenue attribution (5–10%, capped)
- **Purpose:** Zero-risk entry for client; Exo captures upside on measurable KPIs

## The Frontend: 90-Day BOT Engine

**Build-Operate-Transfer** — the zero-friction, compressed implementation program:

| Phase | Days | Focus |
|-------|------|-------|
| BUILD | 1–30 | Ingest fragmented database, clean dirty data, deploy core OS |
| OPERATE | 31–75 | Run AI departments in sandbox; client sees live autonomous workflows |
| TRANSFER | 76–90 | Hand over admin keys + total data sovereignty |

**Pricing:** Break-even ($25K–$35K flat) — the objective is embedding backend monetization, not profiting on setup.

## The Backend: Multi-Department Monetization

Post-transfer, the infrastructure remains dependent on specialized backend departments — this is where long-term enterprise value compounds:

1. **Custom Infrastructure & Hardware** — Private cloud / GPU clusters. Hardware markup + $1,500/month maintenance retainer.
2. **Fine-Tuning & Data Refinement** — Monthly model fine-tuning cycle. Tiered subscription by data volume (~$2,000/month for 500GB).
3. **Specialized Agent Marketplace** — Plug-and-play workflow modules (legal, supply chain, etc.). $1,000/month per active advanced agent.
4. **Security, Compliance & Guardrails** — Continuous security patches + data leakage prevention. $1,200/month compliance licensing fee.

## Why This Wins (Psychological Profile)

- **High-trust frontend:** Client owns the asset by Day 90 — no predatory permanent contract
- **Invisible frictionless upsells:** Backend departments framed as critical utility dependencies (compute, security, data cleaning) — easier for procurement to approve than traditional service upcharges
