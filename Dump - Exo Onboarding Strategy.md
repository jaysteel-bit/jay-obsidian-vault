## Quick Thoughts

**On-Ramping Structure—EXA as Utility Wedge**

Onboarding messaging needs to:
- Be upfront that prospect will need to take a call at some point in their journey
- Explain they can 100% use service for free in exchange for us giving them a call
- Position as: "We want to make sure you like it and set you up properly" (not gates/limitations)
- BOM/T personalized setup continues usage OR triggers when new department is needed

**Key angle:** Makes the brand/software feel like a **luxury service** (concierge approach) rather than a **broken tool that is gated**

---

## Key Insights

- The call is a feature, not a friction point
- Reframe from "you have to talk to us" → "we'll help you set this up right"
- Free tier with optional premium support is a luxury positioning, not a limitation
- EXA as the wedge that opens doors to deeper functionality —
